# ChatGPT로 장면 이미지 만들기 (복사해서 붙여 넣기)

**한 대화창에서** 아래 메시지를 순서대로 하나씩 보낸다. 한 번에 여러 장면을 보내면 한 장에 모아 그리니 꼭 하나씩.

## 메시지 1 — 규칙 + 캐릭터

```
지금부터 1분짜리 세로 쇼츠 애니메이션의 장면 그림을 하나씩 만들 거야. 규칙:
- 이미지 한 장에 장면 하나만. 여러 장면을 한 장에 모으지 마.
- 세로 비율(가능한 가장 긴 세로), 주인공은 화면 가운데에서 위쪽, 아래 1/4은 단순하게.
- 글자·숫자·라벨·자막·로고는 절대 넣지 마.
- 스타일: 3D 애니메이션 영화(픽사 느낌), 부드러운 영화 조명, 짙은 남색·보라색 배경에 청록·분홍 네온 포인트.

주인공은 「큐비」야: 반투명한 유리로 된 작고 동그란 구슬 로봇, 안에 청록색으로 빛나는 에너지 핵과
그 안에서 도는 작은 화살표, 크고 표정이 풍부한 눈 두 개, 공중에 떠 있는 작은 손 두 개.
먼저 큐비 캐릭터 한 장만 그려 줘.
```

마음에 들면 다음으로. 아니면 `다시` 또는 `눈을 더 크게`처럼 고칠 점만 말한다.

## 메시지 2~11 — 장면 (하나 받을 때마다 다음 것)

각 메시지는 앞의 규칙을 다시 상기시키도록 끝에 `(세로, 글자 없이, 같은 큐비)`를 붙였다.

```
장면 01: 어두운 우주 같은 서버실 위쪽에 큐비가 떠서 반갑게 웃으며 손을 흔든다. 빛나는 입자들이 주위를 돌고, 아래 절반은 어둡고 비어 있다. (세로, 글자 없이, 같은 큐비)
```
```
장면 02: 왼쪽에 옛날 전등 스위치, 오른쪽에 큐비가 청록색과 분홍색 두 모습으로 반투명하게 겹쳐 아른거린다. (세로, 글자 없이, 같은 큐비)
```
```
장면 03: 큐비가 수십 개의 작은 빛나는 구슬로 복제되어 격자처럼 늘어서고, 가는 빛의 실이 모두를 이어 은하처럼 퍼진다. 위에서 내려다본 구도. (세로, 글자 없이, 같은 큐비)
```
```
장면 04: 실험실에서 큐비 주위로 열기 아지랑이와 전기 잡음이 일고, 큐비는 빛이 회색으로 바래며 빙글빙글 눈에 땀방울을 흘린다. 옆에 모래가 빠르게 빠지는 모래시계. (세로, 글자 없이, 같은 큐비)
```
```
장면 05: 헤드셋을 쓴 관제사 큐비가 분홍·금색·초록 빛 상자들을 양자 칩 위 4×4 착륙장에 차례로 내려앉힌다. (세로, 글자 없이, 같은 큐비)
```
```
장면 06: 크리스털 호텔 로비에서 안내원 큐비가 작은 구슬 손님에게 빛나는 열쇠를 건네고, 빛줄기가 서로 다른 층의 방으로 이어진다. (세로, 글자 없이, 같은 큐비)
```
```
장면 07: 친근한 레트로 컴퓨터 로봇이 큐비를 그래픽카드처럼 가슴 슬롯에 꽂는다. 뒤에 금빛 샹들리에 냉각 장치, 레이저 이온 트랩, 빛나는 광자 칩. (세로, 글자 없이, 같은 큐비)
```
```
장면 08: 작은 큐비 아홉 명이 손을 잡고 원을 만들어 가운데 금빛 큐비를 지킨다. 둘은 빨갛게 지직거리고 나머지가 빛으로 고쳐 준다. (세로, 글자 없이, 같은 큐비)
```
```
장면 09: 아른거리던 큐비 앞에 거대한 돋보기가 다가오고 플래시가 번쩍 터지는 순간, 큐비가 깜짝 놀라 굳는다(동그란 눈, 벌린 입). (세로, 글자 없이, 같은 큐비)
```
```
장면 10: 큐비가 손을 흔들며 별빛 꼬리를 남기고 별이 가득한 밤하늘 맨 위쪽으로 떠오른다. 가운데는 넓게 어둡고 비어 있다. (세로, 글자 없이, 같은 큐비)
```

## 잘 안 될 때

| 증상 | 이렇게 보낸다 |
|---|---|
| 여러 장면이 한 장에 | `한 장에 한 장면만 다시. 방금 장면만 세로로.` |
| 글자가 들어감 | `글자 없이 똑같이 다시` |
| 가로로 나옴 | `세로로 다시` |
| 큐비가 달라짐 | `처음 그린 큐비와 똑같은 모습으로 다시` |
| 무료 한도에 걸림 | 남은 장면은 Gemini에서 큐비 그림을 첨부하고 같은 문장으로 이어 만든다 |
