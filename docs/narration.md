# AI 내레이션 대본 & 사용법

## 1. 대본 (장면마다 따로 생성해서 저장)

- **글자 수 원칙:** 한국어 TTS는 보통 1초에 5~6음절을 읽는다. 「말할 수 있는 시간 × 5」음절 안으로 맞췄다
  (말할 수 있는 시간 = 장면 길이 − 앞 0.3초 − 뒤 0.15초).
- **TTS에 넣는 칸**을 그대로 복사해 쓴다. 숫자·영어는 TTS가 엉뚱하게 읽는 일이 많아 **소리 나는 대로** 적었다
  (화면 자막은 원래 표기 그대로 나온다).

| 파일 | 장면(시간) | 말할 시간 | TTS에 넣는 칸 | 음절 |
|---|---|---|---|---|
| `01.mp3` | 타이틀 (0–5초) | 4.5초 | 큐비트에게도, 운영체제가 필요할까? | 15 |
| `02.mp3` | 비트와 큐비트 (5–13초) | 7.5초 | 비트는 영 아니면 일. 하지만 큐비트는 영과 일을 동시에 품을 수 있어요. 이걸 중첩이라고 해요. | 37 |
| `03.mp3` | 2ⁿ (13–20초) | 6.5초 | 큐비트가 하나 늘 때마다 상태는 두 배. 오십 개면 무려 천조 개가 넘어요. | 28 |
| `04.mp3` | 결어긋남 (20–28초) | 7.5초 | 문제는 큐비트가 금방 잊어버린다는 거예요. 결어긋남 때문에, 계산엔 마감 시간이 있죠. | 35 |
| `05.mp3` | 스케줄링 (28–33초) | 4.5초 | 첫째, 스케줄링. 여러 사람의 회로를 한 칩에 나눠 실어요. | 22 |

| `10.mp3` | 한줄 평 (55–60초) | 4.5초 | 짧은 순간을 나눠 쓰게 하는 것. 그게, 양자 오에스예요. | 21 |

> **사실 확인:** 2⁵⁰ = 1,125,899,906,842,624 ≈ 1,126조이므로 "천조 개가 넘어요"는 맞는 말이다.

**쉼표의 역할:** TTS는 쉼표에서 살짝 쉰다. "그게, 양자 오에스예요"처럼 강조하고 싶은 말 앞에 쉼표를 넣으면 한줄 평이 또렷해진다.

## 2. 툴 고르기 (무료 조건은 2차 자료 기준 — 쓰기 전에 공식 약관 확인)

| 툴 | 장점 | 무료 조건 (확인된 범위) |
|---|---|---|
| **네이버 클로바더빙** | 한국어 목소리가 자연스럽고 종류가 많다. 문장별로 나눠 내려받기 쉽다 | 비영리·무료 채널, **출처 표기 필수**, 월 다운로드·글자 수 한도 있음 |
| **ElevenLabs** | 감정 표현이 풍부, 다국어 모델로 한국어 지원 | 비상업만, **출처 표기 필요**(문구는 공식 도움말에서 확인) |
| 타입캐스트 · CapCut TTS | 쓰기 쉬움 | 각 서비스 약관 확인 |

학교 과제는 비상업 용도라 무료로 써도 되지만, **출처 표기는 꼭 한다** → `compose.py` 맨 위의
`VOICE_CREDIT = "음성: 네이버 클로바더빙"`처럼 적으면 한줄 평 화면 아래에 작게 들어간다. 레포트에도 적는다.

**목소리 고르는 팁:** 쇼츠는 **밝고 또렷한 20~30대 목소리**, 속도는 **보통~약간 빠르게(1.0~1.1배)**가 잘 맞는다.
10개 파일 모두 **같은 목소리·같은 속도**로 만들어야 한 사람이 말하는 것처럼 들린다.

## 3. 넣고 돌리기

1. 생성한 파일을 `voice/01.mp3` ~ `voice/10.mp3`로 저장한다 (mp3 · wav · m4a · ogg 모두 가능, 번호로만 찾는다)
   - 통으로 한 파일만 만들었다면 `voice/full.mp3` — 0초부터 그대로 깔린다 (타이밍은 직접 맞춰야 함)
2. **소리만 먼저 확인** (몇 초면 끝남):
   ```bash
   python3 compose.py --audio
   ```
   장면마다 「길이/허용 시간」 표가 나온다. `넘침!`이 뜬 장면은 대본을 줄이거나 TTS 속도를 올려 다시 생성한다.
   `mix.wav`를 들어 본다.
3. 완성본:
   ```bash
   python3 compose.py
   ```

**스크립트가 자동으로 해 주는 것**
- TTS 파일 앞뒤 무음 잘라 내기 → 장면 시작 **0.3초 뒤**에 정확히 말을 시작
- 파일마다 다른 음량을 같은 크기로 맞추기
- 허용 시간보다 조금(1.25배 이내) 길면 음 높이를 유지한 채 살짝 빠르게
- **더킹:** 말하는 동안 배경음악을 30%로 줄이고, 말이 끝나면 다시 키우기 (`DUCK` 값으로 조절)
