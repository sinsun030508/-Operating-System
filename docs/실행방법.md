# compose.py 실행 방법

## 준비물 (처음 한 번만)

| 준비물 | Windows | Mac |
|---|---|---|
| Python 3.9 이상 | python.org 에서 설치 — **「Add python.exe to PATH」 체크 필수** | `brew install python` (또는 python.org) |
| ffmpeg (영상·소리 처리) | `winget install Gyan.FFmpeg` → **터미널을 닫았다 다시 연다** | `brew install ffmpeg` |
| 파이썬 라이브러리 | `pip install pillow numpy` | `pip3 install pillow numpy` |

설치 확인 (버전이 찍히면 성공):
```
python --version      (Mac: python3 --version)
ffmpeg -version
```

## 터미널을 키트 폴더에서 열기

- **Windows:** 탐색기에서 저장소 폴더를 연다 → 위쪽 주소창을 클릭 → `cmd` 입력 → Enter
- **Mac:** 터미널을 열고 `cd ` (cd 뒤에 한 칸) 입력 → 폴더를 터미널 창으로 끌어다 놓기 → Enter

## 실행 (Mac 은 python → python3)

```
python compose.py --preview    장면 10개 미리보기 → preview_ai.png  (몇 초)
python compose.py --audio      소리만 합성 + 장면별 길이표 → mix.wav  (몇 초)
python compose.py              완성본 → media/quantum_os_ai.mp4  (1~3분)
```

추천 순서: 클립 몇 개 넣고 `--preview` → 음성 넣고 `--audio` → 마지막에 완성본.

## 폴더 구조

```
(저장소)/
├─ compose.py, make_video.py
├─ docs/    레포트·프롬프트·대본
├─ media/   완성 영상
├─ clips/   01_xxx.mp4 ~ 10_xxx.mp4   (없으면 기존 애니메이션으로 대체)
├─ voice/   01.mp3 ~ 10.mp3           (없으면 배경음악만)
└─ fonts/   (선택) 원하는 한글 폰트 .ttf/.otf — 있으면 이걸 먼저 쓴다
```

## 자주 나는 오류

| 메시지 | 원인 → 해결 |
|---|---|
| `'python'은(는) ... 아닙니다` | PATH 미등록 → `py compose.py` 로 실행하거나, Python 재설치 시 PATH 체크 |
| `'ffmpeg'은(는) ... 아닙니다` / `FileNotFoundError: ffmpeg` | 설치 후 터미널을 다시 안 열었다 → 터미널을 닫고 다시 열기 |
| `ModuleNotFoundError: No module named 'PIL'` | `pip install pillow numpy` |
| `[폰트 없음] 한글 폰트를...` | `fonts/` 폴더를 만들고 한글 폰트(.ttf) 하나 넣기 (예: Noto Sans KR, Pretendard) |
| 자막 일부가 `^n`, `->` 로 보인다 | 그 폰트에 `ⁿ`·`→` 글자가 없어 자동으로 바꾼 것 → 원래대로 보려면 `fonts/` 에 Noto Sans KR |
| `CalledProcessError` (클립 읽다가) | 클립 파일이 깨졌거나 다운로드가 덜 됨 → 다시 내려받기 |
| 영상 파일이 안 열린다 | 실행 중에 창을 닫았다 → 다시 실행해서 `done:` 이 나올 때까지 기다리기 |
