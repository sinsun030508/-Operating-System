# AI 이미지 프롬프트 (한국어) — 「큐비트에게도 운영체제가 필요할까?」

장면마다 이미지 1장씩, 총 11장(캐릭터 1 + 장면 10)을 만든다. 움직임은 `compose.py`가 넣는다.

## 1. 어디서 만들까

| 사이트 | 주소 | 추천 이유 | 주의 |
|---|---|---|---|
| **Gemini** (1순위) | gemini.google.com | 무료로 쓰기 가장 무난하다는 평. **무료 하루 약 20장**(1K 해상도) — 11장 + 다시 그리기에 충분. 대화로 이어서 고치기 쉬움 | 무료 이미지에 **구석 워터마크**가 붙을 수 있음 → 아래 참고 |
| **ChatGPT** | chatgpt.com | 대화로 이어서 만들고 부분 수정이 쉬움 | 무료는 하루 장수 제한이 있음 |
| **Dreamina** (CapCut) | dreamina.capcut.com | 무료 일일 크레딧, 비율을 메뉴에서 고를 수 있음 | 크레딧 소진 시 다음 날 |

무료 한도는 자주 바뀐다. 각 사이트에서 확인하고, **한 곳이 막히면 다른 곳으로** 이어서 만들면 된다.

> **워터마크 걱정은 안 해도 된다.** 무료 툴은 이미지 오른쪽 아래 구석에 작은 아이콘을 넣기도 한다.
> `compose.py`가 이미지 **아래쪽 6%를 자동으로 잘라 내서** 영상 어느 순간에도 그 구석이 보이지 않는다
> (`TRIM_BOTTOM` 값으로 조절, 0이면 안 자름). 그래서 프롬프트에도 "아래 1/4은 단순하게"를 넣었다.
>
> 참고: Gemini 무료 한도·워터마크 정보는 DataCamp 글(2026) 기준이며 자주 바뀐다.

## 2. 만드는 순서 (중요)

1. **한 대화창에서** 아래 「캐릭터 시트」를 먼저 넣어 큐비를 만든다. 마음에 들 때까지 다시 만든다
2. **같은 대화창에서** 장면 01 → 10 순서로 **한 번에 하나씩** 넣는다. 여러 장면을 한꺼번에 주면 AI가 **한 장에 모아 그린다**
   (칸이 작고 가로형이라 영상에 못 쓴다). 맨 처음에 이렇게 규칙을 정해 두면 안전하다:
   `지금부터 장면을 하나씩 따로 그려 줘. 이미지 한 장에 한 장면만, 세로 9:16, 글자·라벨·번호 없이.`
   그다음부터는 장면 프롬프트를 하나씩 보내고, 다 되면 `다음 장면`처럼 이어 간다.
   장면 01 → 10 순서로 넣는다. 대화가 이어지면 앞에서 만든 큐비를 기억해 생김새가 비슷하게 유지된다
   - 다른 사이트로 옮기면: 마음에 든 큐비 이미지를 **첨부**하고 "이 캐릭터로"라고 붙인다
3. 각 장면 프롬프트 **끝에 「공통 문구」**를 붙인다
4. 내려받아 `clips/01.png` ~ `clips/10.png`로 저장한다 (jpg · webp도 됨)

## 3. 공통 문구 (모든 장면 끝에 붙이기)

```
3D 애니메이션 영화 스타일(픽사 느낌), 부드러운 영화 조명, 짙은 남색과 보라색 배경에 청록색·분홍색 네온 포인트,
세로 9:16 비율, 주인공은 화면 가운데에서 위쪽, 화면 아래 1/4은 비교적 단순하게, 글자·자막·로고·워터마크 없이
```

> **왜 "아래 1/4은 단순하게"?** 영상에서 화면 아래에 자막 상자가 올라간다. 그 자리에 중요한 게 있으면 가려진다.
> **왜 "글자 없이"?** AI는 한글을 깨진 모양으로 그린다. 자막은 코드가 정확하게 넣는다.

## 4. 캐릭터 시트 — 큐비

```
「큐비」라는 귀여운 캐릭터를 디자인해 줘. 반투명한 유리로 된 작고 동그란 구슬 로봇이고,
안에는 청록색으로 빛나는 에너지 핵과 그 안에서 천천히 도는 작은 화살표가 있어.
크고 표정이 풍부한 LED 눈 두 개, 공중에 떠 있는 작은 손 두 개, 가장자리에 은은한 빛.
전신이 보이게 화면 가운데에.
```
(+ 공통 문구)

## 5. 장면 10개

> 모든 장면 앞에 `방금 만든 큐비가 나오는 장면 한 컷:`을 붙이면 같은 캐릭터를 유지하기 쉽다.

**01 · 타이틀 (0–5초)** — 영상에서는 천천히 다가간다
```
어두운 우주 같은 서버실 위쪽에 큐비가 떠서 반갑게 웃고 있다. 빛나는 입자들이 큐비 주위를 돌고,
뒤로 서버 랙이 별빛 속으로 흐려진다. 화면 아래 절반은 어둡고 비어 있다(제목 자리).
```

**02 · 비트와 큐비트 (5–13초)** — 천천히 물러난다
```
왼쪽에는 평범한 옛날 전등 스위치가 하나 있다. 오른쪽에는 큐비가 반투명한 두 모습으로 겹쳐 보인다 —
하나는 청록색, 하나는 분홍색으로 빛나며 서로 겹쳐 아른거린다(동시에 두 상태).
```

**03 · 지수적으로 커지는 상태 (13–20초)** — 왼쪽에서 오른쪽으로 흐른다 (가로로 넓은 그림이면 좋음)
```
큐비가 수십 개의 작은 빛나는 구슬로 복제되어 격자처럼 늘어서 있고, 가는 빛의 실이 모두를 이어
은하처럼 바깥으로 퍼져 나간다. 멀리서 내려다본 넓은 구도.
```

**04 · 큐비트는 금방 잊는다 — 결어긋남 (20–28초)** — 위에서 아래로 흐른다 (세로로 긴 그림이면 좋음)
```
실험실 안의 큐비 주위로 열기 아지랑이, 진동, 지지직거리는 전기 잡음이 일어난다. 큐비의 청록빛이 회색으로
바래 가고 어지러운 표정(빙글빙글 눈, 땀방울)이다. 옆에는 모래가 빠르게 빠지는 작은 모래시계.
```

**05 · 스케줄링 (28–33초)** — 천천히 다가간다
```
작은 헤드셋을 쓴 관제사 큐비가 분홍·금색·초록색으로 빛나는 상자들을 미래형 양자 칩 위의
4×4 착륙장에 차례로 내려앉히고 있다. 위에서 비스듬히 내려다본 구도.
```

**06 · 가상 큐비트 주소 (33–38초)** — 천천히 물러난다
```
크리스털로 된 호텔 로비에서 안내원 큐비가 작은 구슬 손님들에게 빛나는 열쇠를 건넨다.
각 열쇠에서 나온 빛줄기가 건물의 서로 다른 층, 서로 다른 방으로 이어진다. 어떤 방은 더 밝게 빛난다.
```

**07 · 드라이버 (38–43초)** — 왼쪽에서 오른쪽으로 흐른다
```
친근한 레트로 대형 컴퓨터 로봇이 큐비를 그래픽카드처럼 가슴의 빛나는 슬롯에 조심스럽게 꽂는다.
뒤로 세 가지 기계가 빛난다: 금빛 샹들리에 모양 냉각 장치, 가는 레이저가 나오는 이온 트랩, 빛이 흐르는 광자 칩.
```

**08 · 양자 오류 정정 (43–48초)** — 위에서 아래로 흐른다
```
작은 큐비 아홉 명이 손을 잡고 원을 만들어 가운데의 더 큰 금빛 큐비를 지킨다.
둘은 빨갛게 지직거리고, 나머지가 더 밝게 빛나며 그 둘을 고쳐 주고 있다.
```

**09 · 디버깅의 역설 — 측정 (48–55초)** — 천천히 다가간다
```
여러 겹으로 아른거리던 큐비 앞에 거대한 돋보기가 다가오고, 카메라 플래시가 번쩍 터지는 순간.
큐비는 하나의 단단한 모습으로 굳어 깜짝 놀란 표정(동그란 눈, 벌린 입)이다.
```

**10 · 한줄 평 (55–60초)** — 천천히 물러난다
```
큐비가 손을 흔들며 별이 가득한 밤하늘의 맨 위쪽으로 천천히 떠오른다. 따뜻하고 희망적인 빛,
부드러운 별빛 보케. 화면 가운데는 넓게 어둡고 비어 있다(글자 자리).
```

## 6. 잘 안 될 때 (같은 대화창에서 이어서 말하기)

| 증상 | 이렇게 말한다 |
|---|---|
| 여러 장면이 한 장에 모여 나왔다 | `이 장면들을 하나씩 따로 그려 줘. 한 장에 한 장면, 세로 9:16, 글자 없이. 먼저 01번부터` |
| 글자가 들어갔다 | `글자 없이 똑같이 다시 그려 줘` |
| 가로나 정사각형으로 나왔다 | `세로 9:16 비율로 다시 그려 줘` |
| 큐비 생김새가 달라졌다 | `처음에 만든 큐비와 똑같은 모습으로 다시` (+ 큐비 이미지 첨부) |
| 주인공이 아래쪽에 있다 | `주인공을 화면 위쪽으로 올려 줘` |
| 너무 복잡하다 | `배경을 더 단순하게, 주인공을 더 크게` |

## 7. 진짜 애니메이션으로: 이미지 → 영상 AI (움직임 프롬프트)

위에서 만든 장면 이미지를 영상 AI에 **첫 프레임으로 넣고 움직임만** 적는다. 캐릭터가 이미 정해져 있어
장면마다 큐비가 달라지지 않고, 처음부터 그리게 할 때보다 실패가 적어 **크레딧이 덜 든다.**

- **어디서:** Kling · PixVerse · Dreamina(매일 무료 크레딧이 들어온다는 자료가 있음), Hailuo(가입 체험) —
  한 곳의 크레딧이 떨어지면 다른 곳에서 이어 만든다. 무료 조건은 사이트에서 확인
- **설정:** 이미지 → 영상(Image to Video), 9:16, 5초, 소리 생성은 끄기
- **우선순위:** 다 못 만들어도 된다. **01 타이틀 → 09 측정 → 04 결어긋남 → 10 한줄 평** 순으로 만들고,
  나머지는 이미지 그대로 둔다 (아래 「영상이 없는 장면」 참고)
- **저장:** `clips/01.mp4`처럼 같은 번호로 넣는다. **같은 번호에 영상과 이미지가 둘 다 있으면 영상이 쓰인다**

모든 장면 끝에 `캐릭터 모습 그대로 유지, 글자 없이`를 붙인다.

| 장면 | 움직임 프롬프트 |
|---|---|
| 01 | 큐비가 둥실 떠오르며 손을 흔들고 눈을 깜빡인다. 주변 입자가 천천히 돈다 |
| 02 | 스위치가 딸깍 켜졌다 꺼지고, 두 큐비가 겹쳤다 갈라졌다 하며 아른거린다 |
| 03 | 구슬들이 하나씩 켜지며 빛의 실이 바깥으로 퍼져 나간다. 카메라가 천천히 물러난다 |
| 04 | 큐비가 부르르 떨고 빛이 깜빡이다 흐려진다. 모래시계 모래가 빠르게 떨어진다 |
| 05 | 빛나는 상자들이 날아와 칸에 하나씩 내려앉고, 큐비가 손짓으로 안내한다 |
| 06 | 큐비가 열쇠를 건네자 빛줄기가 방으로 흘러가 불이 하나씩 켜진다 |
| 07 | 로봇이 큐비를 슬롯에 꽂자 화면 얼굴이 웃고, 뒤의 기계들이 차례로 켜진다 |
| 08 | 빨갛게 지직거리던 두 큐비가 친구들의 빛을 받아 청록색으로 돌아온다 |
| 09 | 돋보기가 다가오고 플래시가 번쩍 터지자 큐비가 깜짝 놀라 굳는다 |
| 10 | 큐비가 손을 흔들며 별빛 꼬리를 남기고 위로 떠오른다 |

### 영상이 없는 장면 — 이미지가 스스로 움직인다

영상 AI 크레딧이 모자라 이미지로 남은 장면도 `compose.py`가 움직임을 넣는다.

| 장면 | 코드로 넣는 움직임 |
|---|---|
| 모든 이미지 장면 | 카메라 움직임(다가가기·물러나기·가로/세로 흐름), 떠다니며 반짝이는 빛 입자, 숨 쉬듯 밝기 변화 |
| 02 중첩 | 화면 색이 청록 ↔ 분홍으로 아른거림 |
| 04 결어긋남 | 갈수록 심해지는 떨림, 색이 회색으로 바램, 빛 깜빡임, 지지직 잡음 줄 |
| 09 측정 | 효과음과 같은 순간(50.6초) 하얀 플래시 |
| 10 한줄 평 | 빛 입자가 위로 떠오름 |

## 8. 넣고 확인

```bash
python compose.py --preview    # 10장면 미리보기 → preview_ai.png
python compose.py              # 완성본 → media/quantum_os_ai.mp4
```

또는 이미지와 음성 파일을 채팅에 첨부하면 합성·검사·레포트 갱신까지 해 준다.
